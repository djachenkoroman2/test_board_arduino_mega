Подготовь в текущем репозитории рабочий проект PlatformIO для платы Arduino Mega 2560.

Требования:

1. Используй платформу Atmel AVR, плату `megaatmega2560` и Arduino framework.
2. Настрой в `platformio.ini` не менее двух независимых окружений PlatformIO для одной и той же платы.
3. Для каждого окружения создай отдельный каталог с исходным кодом. Организуй структуру так, чтобы при сборке окружения компилировались только относящиеся к нему файлы, а исходники остальных окружений не попадали в сборку. Для выбора исходников используй штатные возможности PlatformIO, например `build_src_filter`.
4. Добавь в каждое окружение минимальный, но самостоятельно компилируемый Arduino-скетч с функциями `setup()` и `loop()`. Код окружений должен различаться настолько, чтобы было очевидно, что они собираются независимо.
5. Не добавляй лишние зависимости и не изменяй файлы, не относящиеся к задаче.
6. Кратко опиши структуру проекта и приведи команды для сборки каждого окружения.

Критерии готовности:

- `platformio.ini` корректен и содержит не менее двух окружений;
- у каждого окружения есть собственный каталог исходников;
- каждое окружение успешно собирается отдельно командой `pio run -e <имя_окружения>`;
- сборка одного окружения не включает исходники другого;
- в итоговом ответе перечислены созданные или изменённые файлы и результаты проверки сборки.

Перед завершением выполни сборку всех созданных окружений. Если PlatformIO недоступен, явно сообщи об этом и укажи команды, которыми следует выполнить проверку.
