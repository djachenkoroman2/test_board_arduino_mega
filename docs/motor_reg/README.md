# Проверка ESC на Arduino Mega 2560

Окружение `motor_reg` формирует типовой управляющий сигнал RC ESC на цифровом пине `D2`. Для формирования импульсов используется стандартная библиотека Arduino `Servo` и `writeMicroseconds()`. Обычный `analogWrite()` здесь не применяется: большинство RC ESC ожидают сервосигнал с длительностью импульса примерно 1000–2000 мкс.

Официальная библиотека `arduino-libraries/Servo` указана в `lib_deps` окружения и устанавливается PlatformIO при первой сборке.

> **Опасность:** после включения программа автоматически начнёт разгон до заданного максимума. Первую проверку проводите только со снятым пропеллером или без другой механической нагрузки. Надёжно закрепите двигатель и обеспечьте возможность немедленно отключить силовое питание ESC.

## Подключение

| Контакт | Подключение |
|---|---|
| Сигнальный провод ESC | `D2` Arduino Mega |
| Земля управляющего разъёма ESC | `GND` Arduino Mega |
| Силовые входы ESC | Отдельный аккумулятор или источник с напряжением и током, допустимыми для ESC и двигателя |
| Три фазных выхода ESC | К трём проводам бесколлекторного двигателя |

Земля ESC и земля Arduino должны быть объединены, иначе уровень сигнала на `D2` не будет иметь общей точки отсчёта. Двигатель и силовую часть ESC нельзя питать от контакта `5V` Arduino: этот контакт не рассчитан на такой ток.

Если ESC имеет встроенный BEC и вывод `5V` в управляющем разъёме, перед его подключением проверьте документацию ESC. Не соединяйте выход BEC с уже запитанной линией `5V` Arduino, пока не убедитесь, что такое включение допустимо. Для первой проверки Arduino можно питать от USB, подключив к управляющему разъёму ESC только сигнал и общую землю.

## Алгоритм

Программа работает как неблокирующий автомат состояний на основе `millis()`:

1. `arming` — в течение 5 секунд удерживает импульс 1000 мкс;
2. `ramp up` — увеличивает импульс с 1000 до 2000 мкс шагами по 10 мкс каждые 50 мс;
3. `hold maximum` — удерживает максимум 2 секунды;
4. `ramp down` — уменьшает импульс с теми же шагом и интервалом;
5. `hold minimum` — удерживает минимум 3 секунды, затем цикл повторяется.

Переходы между состояниями и текущая длительность импульса выводятся в последовательный порт со скоростью 115200 бод. Статус обновляется не чаще одного раза в 500 мс.

## Настройка

Параметры находятся в начале `src/motor_reg/main.cpp`:

| Константа | Значение | Назначение |
|---|---:|---|
| `kEscSignalPin` | `2` | Цифровой пин сигнала ESC (`D2`) |
| `kMinimumPulseUs` | `1000` мкс | Минимальная тяга |
| `kMaximumPulseUs` | `2000` мкс | Максимальная тяга |
| `kPulseStepUs` | `10` мкс | Изменение импульса за один шаг |
| `kRampStepIntervalMs` | `50` мс | Интервал между шагами разгона и торможения |
| `kArmingDurationMs` | `5000` мс | Начальное удержание минимальной тяги |
| `kMaximumHoldDurationMs` | `2000` мс | Пауза на максимуме |
| `kMinimumHoldDurationMs` | `3000` мс | Пауза на минимуме между циклами |
| `kTelemetryIntervalMs` | `500` мс | Интервал вывода состояния в Serial |

Диапазон 1000–2000 мкс является типовым, но не универсальным. Некоторые ESC используют другие пределы, требуют отдельной процедуры калибровки или не разрешают запуск после простой подачи минимального сигнала. Перед подключением двигателя проверьте руководство производителя ESC. Для первых испытаний разумно временно уменьшить `kMaximumPulseUs`.

## Безопасный первый запуск

1. Снимите пропеллер и любую другую опасную механическую нагрузку.
2. Закрепите двигатель и ESC на негорючей поверхности с достаточным охлаждением.
3. Не подключая силовое питание ESC, соедините `D2`, общую землю и двигатель согласно схеме.
4. Соберите и загрузите прошивку на Arduino.
5. Откройте последовательный монитор и убедитесь, что программа начинается в состоянии `arming` с импульсом 1000 мкс.
6. Подготовьте доступный выключатель или разъём для немедленного отключения аккумулятора ESC.
7. Только после этого подайте силовое питание на ESC. Учтите, что через 5 секунд программа начнёт автоматический разгон.
8. При неверной последовательности звуков ESC, рывках двигателя или перегреве сразу отключите силовое питание и сверьтесь с инструкцией ESC.

## Команды PlatformIO

Сборка:

```bash
pio run -e motor_reg
```

Загрузка прошивки (выполнять только после безопасной подготовки стенда):

```bash
pio run -e motor_reg -t upload
```

Последовательный монитор:

```bash
pio device monitor -e motor_reg
```
